# First PR Practice

A tiny sandbox repo for practicing the GitHub pull request workflow: branch, commit, push, open a PR, merge.

## What this is

This repo exists so you can get comfortable with the basic loop of contributing to a project on GitHub:

1. Make a change on a branch
2. Commit it
3. Push the branch
4. Open a pull request
5. Merge it

## Usage

There isn't any code to run here yet, it's just a starting point.
